# Иконка на домашнем экране (без установки интеграции)

PWA-манифест Home Assistant вшит в его фронтенд, поэтому «Добавить на главный
экран» на любом дашборде всегда даёт иконку **Home Assistant** — ни настройкой,
ни темой, ни параметром панели это не меняется.

Эти два файла — страница-лаунчер: у неё **своя** иконка, и она перенаправляет на
ту панель, которую вы укажете. Установив её, вы получаете на домашнем экране
приложение с нужной иконкой, открывающее ваш дашборд без адресной строки.

Иконки вшиты как `data:`-адреса, загружать больше нечего — всё лежит в двух
текстовых файлах.

## Установка

1. Скопируйте `index.html` и `manifest.json` в `config/www/dom/` на машине с
   Home Assistant (файловый редактор, Samba, VS Code или SSH — что есть).
   Создайте `www`, если папки не было, и один раз перезапустите HA.
2. На телефоне откройте — один раз, с `?to=`, указывающим на вашу панель:

       http://<адрес-HA>:8123/local/dom/?to=/lovelace/0

3. Меню Chrome → **Установить** / **Добавить на главный экран**.

`?to=` запоминается на устройстве, поэтому установленное приложение (оно
стартует без строки запроса) продолжает открывать ту же страницу. Значение
проверяется по origin самой страницы, так что подсунутая ссылка не уведёт
приложение на чужой сайт.

Если у вас установлена интеграция **BMS Планировка**, эти файлы не нужны совсем:
она отдаёт такой же лаунчер по адресу `/bms-floorplan-app?to=…&name=…`.
